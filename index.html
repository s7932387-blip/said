DRAFTSIM

Офлайн-терминал драфтов для Яндекс Игр. Живой ростер и портреты с OpenDota API и CDN OpenDota, локальная база на 125+ героев, три режима и честная аналитика матч-апов.

Режимы

  • ОДИНОЧНАЯ ИГРА · лёгкий / средний / сложный бот
  • ПЕСОЧНИЦА · ручной ввод всех 10 пиков
  • РЕНКЕД ПОМОЩНИК · живой тренер контр-пиков

Модель аналитики

  • Нулевая сумма профиля героя (роли + атрибут + тип атаки)
  • Значение команды = строгое среднее пяти профилей
  • Шанс победы = логистика от разницы рейтингов (D = 144)
  • Текст вердикта строится только из таблицы сравнения

02Как работает песочница

  • Пики идут строго по цепочке: 1-й слот Света → 1-й слот Тьмы → 2-й слот Света → 2-й слот Тьмы и так далее до 10 героев.
